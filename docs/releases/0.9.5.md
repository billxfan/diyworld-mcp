# DIYworld MCP 0.9.5

Release date: 2026-08-09

## Fixed

- Declare Codex `experimentalApi` capability before using isolated World Host
  fields such as `runtimeWorkspaceRoots`.
- Serialize concurrent Codex initialization and discard failed or stale child
  processes before reconnecting.
- Run a fresh ephemeral World Host turn without attempting `thread/resume` or
  `thread/read`, which ephemeral tasks do not support.
- Fence platform Host commits with the World Host runtime version so a result
  cannot commit after a creator takes over.
- Reject persistent per-World Host threads to preserve per-Character private
  context isolation.
- Wake the platform Host when a collective interaction reaches its deadline.
- Strengthen collective-response privacy instructions and remove duplicate
  prewarm error callbacks.

## Verification

- Full Node test suite.
- Release rehearsal against a read-only online-backup copy of the hosted SQLite
  database.
- npm package dry run.
- Real bundled Codex App Server canary covering
  `initialize -> thread/start -> turn/start -> turn/completed` on an ephemeral
  isolated Host task.
