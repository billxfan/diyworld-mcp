# DIYworld MCP 0.9.7

Release date: 2026-08-10

## Fixed

- Require structured objects for Host `effects`, `affected_entities`, and
  `next_affordances` output so malformed model responses are rejected with an
  actionable repair prompt instead of being retried unchanged.
- Allow anomaly claims to progress from `observed` to `verified` or
  `disproved` while preserving immutable claim text and terminal outcomes.
- Bound platform Host processing to three attempts per input or collective
  interaction. Later attempts include the prior validation error for targeted
  repair.
- Terminalize an input or collective batch that still fails after the retry
  limit, return an explicit final `host_failed` result, and continue processing
  later World work instead of blocking the queue.
- Persist Host attempt counts and terminal failure details through additive,
  idempotent SQLite migration columns.
- Fall back once to a macOS notification when a bound Codex task already has
  an active writer, while leaving the durable activity unread and advancing
  the bridge cursor instead of reconnecting forever.
- Add an operational SQLite online-backup command that verifies integrity and
  foreign keys and refuses to overwrite an existing backup.
- Update the external testing guide and test console to use the current
  Character model and the official World name “晨雾镇”.
