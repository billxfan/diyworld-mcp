# 五个官方世界 v6：具体世界、持续剧情与异步影响

> 代码来源：`src/venue-lab-core/official-worlds.js`
> Host Runtime：`src/venue-lab-core/world-agent-system.js`
> 本文是当前正式产品说明。Kimi3 的世界设定用于重做题材、人物与生活逻辑；平台原有的状态权威、即时反馈、首轮信息预算和玩家自主权继续保留。

## 一、这次重构解决什么

v5 已避免一上来展示等级、台账和内部术语，但部分世界的核心概念仍偏抽象，任务像系统流程而不像世界里自然发生的事。

v6 统一要求：

1. 玩家先遇到具体的人、地方和麻烦，再了解规则；
2. 每次提交都立即得到“是否接住、眼前反馈、下一步”；
3. 被接受的公共行动至少形成一种异步影响；
4. 无人在线时不暗扣资源、不制造离线惩罚；
5. NPC 可以提供互动与意见，但不能伪装真人，也不能代替真人表决；
6. 五个世界都有可持续换季或换季式内容，不因一个主线结束而停服。

五个稳定 World ID 不变：

- `official-center-town`
- `official-adventurers-guild`
- `official-city-detective-agency`
- `official-apocalypse-shelter`
- `official-liminal-backrooms`

名称和内容改变不会另建空世界；原有玩家、事件和顶层状态继续迁移。

## 三、五类 Host 的专项能力

### 晨雾镇导演

- 按天气、居民日程和开放事情生成自然的生活入口；
- 把真人行动变成物件变化、居民转述和关系回声；
- 用河汛、集市、收获与寒潮组织公共节奏；
- 不以神秘物件强行制造主线，也不让 NPC 伪造繁荣。

### 风口集导演

- 从商队、生计、天气和人物托付中生成护送、寻人、探路与抢险；
- 让路况、天气、伤势和前人记号保持因果一致；
- 回集后结算交代、养伤、酬劳、名声和公共路线；
- 旧矿难是可选长线，不让所有任务都服务同一个谜团。

### 北桥调查导演

- 案件开放前在 Host 私有区锁定真相、时间线与证据路径；
- 用案件由头、人情与前置事实决定哪些门会打开；
- 多数小案独立成立，约三分之一自然碰到当季长案；
- 白渡口旧案结案后进入余波与新案件季，而不是世界完结。

### 白河守站导演

- 把天气、煤、机器、班次和山下请求组织成具体一班；
- 先反馈人的处境和机器变化，再展示本次相关账目；
- 冬季结束后进入开春去留、汛期、电网转型和下一冬；
- 日常可逆操作可由单人完成，长期公共方向交给真人集体窗口。

### 回廊异常导演

- 依据原创空间语法生成有限、可退回的探索片段；
- 在幕后锁定异常条件，用交叉观察和复走验证；
- 优先让后来者遇到真人留下的刻字、录音、遗失物和后果；
- 失败转为迷路、遗落记录或救援线程，不无预警永久淘汰；
- 不直接采用外部后室 Wiki 的层级、物资与现成实体。

## 四、基座 Host 统一契约

### 首轮

- 先说清现在发生了什么、为什么值得管、行动可能改变什么；
- 只保留一个当前目标和二至三个“动词 + 对象”的方向；
- 首轮最多三个新专有名词，不使用表格欢迎玩家；
- 始终允许玩家自由描述其他行动。

### 每次行动

面向玩家按以下顺序表达：

1. 发生了什么；
2. 玩家刚才的行动得到什么直接反馈；
3. 人物、地点、物品或公共状态发生什么具体变化；
4. 接下来可做什么。

后台可以使用线程、Beat、固定真相、风险表和状态机，但不能把这些字段名当作玩家内容。

### 异步连续性

被接受的公共行动至少形成以下一层：

- 痕迹层：物品、记号、档案、修复或建设；
- 状态层：后来者进入时面对已经改变的共同世界；
- 叙事层：NPC、记录或环境明确转述前人的真实影响。

失败和未完成也可以留下可修复、可纠正或可接续的处境。异步影响只修改世界，不替其他真人行动或表态。

### 无人与多人

- 0 人：暂停自由推进、资源消耗和个人风险；只保留到期事件与既有行动的确定后果；
- 1 人：Host 扮演明确标识的必要 NPC，提供可独立完成并留下公共痕迹的目标；
- 少量玩家：支持同步或异步分工，沉默不代表同意；
- 大量玩家：拆分局部场景，只有全体性事项进入集体窗口；
- 中途加入：只回顾当前局势、前人影响和一个可直接进入的旁路；
- 回流：说明离开后的变化与旧行动回声，再恢复旧目标或提供同价值入口。

## 五、状态与迁移

- 官方规则版本：v6；
- 世界顶层字段继续是 `world_progress` 加各世界原字段：`town`、`adventure`、`mystery`、`settlement`、`backrooms`；
- 成员顶层字段继续是 `journey` 加各世界原字段：`resident`、`adventurer`、`detective`、`operator`、`wanderer`；
- 新字段以回填方式加入，已有值优先，不覆盖玩家历史；
- Host 仍是唯一状态写入者，未声明顶层字段会被状态契约拒绝。

## 六、World Builder 继承要求

后续用户自建世界不复制五个官方题材，但必须从本基座继承：首轮信息预算、即时反馈、异步三层、无人暂停、NPC 身份边界、真人集体决策边界、失败恢复和状态写入契约。World Builder 再根据世界类型生成专项事件源、节奏、NPC、状态与长期换季机制。
