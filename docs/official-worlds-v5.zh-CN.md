# 五个官方世界 v5：先让玩家在意

> 历史版本：当前正式配置已升级至 [official-worlds-v6.zh-CN.md](./official-worlds-v6.zh-CN.md)。本文仅保留为 v5 设计记录。

> 代码来源：`src/venue-lab-core/official-worlds.js`
> 本版依据真实 WorkBuddy 试玩反馈重做首轮体验、任务钩子与 Host 表达。世界 ID 和五种类型保持不变，已有玩家与世界历史继续保留。

## 一、为什么重做

v4 的规则和状态模型完整，但把设计者语言过早暴露给玩家：等级、档案、资源表、规则验证和虚构名词在玩家产生动机前出现。结果是玩家知道“系统要求做什么”，却不知道“自己为什么会想做”。

v5 采用统一顺序：

1. 先发生一件具体的事；
2. 让玩家知道谁受影响、拖延会怎样、哪里反常；
3. 给二至三个方法不同的行动，而不是流程菜单；
4. 行动后立即反馈，并留下可见的世界变化；
5. 等玩家开始关心世界，再逐步解释等级、资源和长线设定。

内部仍然保留状态机、风险结算、固定真相、资源依赖和异常规则，只是不把后台术语当成游戏内容。

## 二、五个世界的新体验承诺

| 世界 | 玩家来这里做什么 | 首轮为什么值得行动 | 长期留下什么 |
|---|---|---|---|
| 晨雾镇 | 生活、交朋友、经营自己的小事业 | 一只专门留给新居民的木箱正在等你 | 住处、关系、店铺、节日与邻里约定 |
| 灰羽城·裂隙公会 | 救人、寻宝、护送、保卫和探索 | 送药人的马独自回来，山村孩子天黑后会断药 | 新路线、人物命运、装备与后续冒险 |
| 灰雨市·雾港街 13 号 | 调查反常案件并找出固定真相 | 失踪三天的人刚刚打来电话 | 可核对的证据、人脉、结案后果与城市秘密 |
| 锈河避难所 | 把勉强活着的据点建设成家 | 今晚的电只够医务室或净水泵其中一处 | 设施、社区规则、获救者与新的生活空间 |
| 失序回廊 | 找路、求生、验证怪事并帮助陌生人 | 电梯开到陌生走廊，电话已响两次，墙上有人警告第三次别接 | 路标、录音、安全路线、救援与出口计划 |

## 三、逐世界设计

### 1. 晨雾镇：一座会记住每个人的小镇

玩家不是来做“社区贡献任务”，而是来建立生活。住哪、认识谁、做什么工作、愿意帮谁，都会逐渐形成个人故事。

首轮场景：雨刚停，车站长椅上有一只写着“交给下一位新居民”的木箱。里面是一把空屋钥匙、三封居民留言和一块仍然温热的苹果派。玩家可以读留言、拿钥匙看房，或追问是谁刚刚送来的。

持续内容分为四层：

- 生活：找房、布置、工作、开店、种植；
- 关系：拜访、送礼、承诺、误会与修复；
- 小镇：集市、节日、公共空间和居民提案；
- 秘密：从日常物件自然长出的旧故事，不抢占生活主线。

多人价值必须具体出现：其他真人留下的食物、钥匙、留言、商店、活动邀请或未完成的约定。没有真人痕迹时，NPC 可以提供生活互动，但不能伪装成玩家制造繁荣。

### 2. 灰羽城·裂隙公会：每次出发都有人等待结果

保留奇异入口和公会框架，但“裂隙、共鸣碎片、D 级档案”等不再承担首轮吸引力。任务必须先有一个值得玩家在意的人、期限或冲突。

首轮场景：一匹无人骑乘的马撞开公会大门。马鞍上有血，送往山村的退烧药少了一半；如果天黑前送不到，村里的孩子会断药。玩家可以检查马和车辙、询问守卫，或带着剩余药立刻追人。

任务池优先顺序：

1. 救援：找到失踪者、带伤员回来；
2. 保卫：守住街区、车队或某个重要人物；
3. 夺回：从危险地点取回有意义的物品；
4. 护送：路途中出现关系与价值选择；
5. 竞速寻宝：其他玩家也能从地图和选择中获益；
6. 探索：发现本身必须连接人物命运或新的行动机会。

任务不默认播报背包清单、等级和所有风险。只有当绳子、口粮、伤势或期限确实改变选择时才说明。失败也要产生故事：救援变成求援、遗失装备被后来者找到、错误路线变成公开警告。

### 3. 灰雨市·雾港街 13 号：从一个“不可能”开始

玩家来这里是为了产生“这到底怎么回事”的冲动。固定真相、证据分类和证伪规则仍是公平推理的后台保证，但 Host 不应像调查教科书一样说话。

首轮场景：凌晨两点，调查所接到失踪三天的电台主播林夏来电。她只说“别让他们重播星期二的节目”，电话便断了；来电位置却是楼下已经拆除的电话亭。

Host 每轮只做三件事：给出可观察的新细节，指出一个自然产生的矛盾，让玩家决定下一步查谁或查哪里。专业词汇改成日常表达，例如说“两份记录不可能同时为真”，而不是要求玩家“提交可证伪假说”。

多人可以分查现场、人物和记录；证据共享，推论可以冲突，真相不靠投票改变。错误判断会伤害关系、浪费时间或让嫌疑人警觉，但必须留下补查路径。

### 4. 锈河避难所：资源背后始终是人的生活

经营系统继续精确结算，但玩家首先看到的不是仪表盘，而是停电的医务室、没水的厨房、漏雨的床铺和门外等待答复的人。

首轮场景：傍晚，发电机冒出黑烟。剩下的电只够医务室呼吸机或净水泵其中一处；储水只够到明天下午。玩家可以先保医务室、先保净水，或冒险带电抢修。

每次经营选择分两层反馈：

- 先说具体变化：灯亮了、病人稳定了、厨房开始限水；
- 再只列与本次行动有关的资源变化和原因。

长期目标不是把数值升满，而是看着废车站出现厨房、温室、诊所、课堂和新居民。重大配给与接纳由真人共同决定；无人在线时暂停消耗，不用离线惩罚逼迫玩家打卡。

### 5. 失序回廊：先害怕和好奇，再研究规则

异常规律仍需跨玩家一致，但玩家开场不需要理解“锚点、暴露值、对照实验”。他们先面对一个熟悉事物突然失常的瞬间。

首轮场景：电梯门打开，外面是潮湿发黄的走廊。墙上写着“林乔，如果你看到这句，别在第三次铃响后接电话。”远处红色电话已经响了两次。玩家可以按住电梯门、检查笔迹，或在第三次铃响前走近电话。

Host 用感官和后果表达后台机制：灯光变暗、退路少了一扇门、粉笔字出现在不该出现的位置。只有玩家主动总结规律时，才把观察整理成记录。

多人价值来自真实遗留物：方向冲突的箭头、一段录音、一件遗失装备、一条求救信息。后来者能够验证、纠正或接续；错误记录不会被静默删除，而会成为危险和故事的一部分。

## 四、五个 Host 的共同表达契约

首轮禁止：

- 用表格或台账欢迎玩家；
- 一次介绍超过三个虚构专有名词；
- 展示内部字段、线程、Beat、状态机或概率表；
- 先讲完整规则，再让玩家选择；
- 用“推进节点、提交档案、提升置信度”替代世界内行动。

每轮必须：

1. 先说明现在发生了什么；
2. 对玩家刚才的行动给出直接反馈；
3. 说明人物、地点或物品发生的具体变化；
4. 给二至三个“动词 + 对象”的下一步；
5. 明确玩家也可以自由描述其他行动。

一个合格任务必须同时拥有：受影响的人或地方、拖延的后果、一个有趣的未知点，以及玩家完成后能看见的改变。

## 五、运行与迁移

- 官方世界规则与规格版本升级为 v5；
- 五个 World ID、分类与状态顶层字段不变；
- 已有公共状态、成员状态、关系与历史事件保留；
- 新首轮 Beat 主要作用于新玩家和没有进行中目标的玩家；
- 回流玩家优先继续其旧目标，再用 v5 的自然语言与信息预算呈现。
